关于 Engine Sound Lab：支持的 28 种引擎声浪与 38 款经典跑车仪表盘清单

Engine Sound Lab 是一款完全运行在浏览器中的免费实时物理引擎声浪合成器（Rust → WebAssembly + Web Audio API），无需任何音频录音文件，实时模拟气缸点火顺序、活塞运动与进排气声波导管共振。

28 种引擎声浪预设：日系 JDM（本田 Civic Type R 直四、S2000 高转自吸、丰田 Supra 2JZ-GTE 直六涡轮、日产 GT-R VR38 双涡轮 V6、马自达 RX-7 13B 双转子、斯巴鲁 WRX STI 水平对置四缸、三菱 Evo IX、GR Yaris 三缸）、欧美街车与超跑（美式十字曲轴 V8、法拉利 458 平面曲轴 V8、保时捷 911 GT3 水平对置六缸、宝马直列六缸、奥迪 RS3 直列五缸、雷克萨斯 LFA / Carrera GT 高转 V10、法拉利 812 / 兰博基尼 Aventador 自吸 V12、布加迪 W16）、F1 赛车（90 年代 F1 V12、2006 F1 V8、NASCAR V8）、经典摩托车（雅马哈 R1、本田 CBR、杜卡迪 90° L-Twin、哈雷 45° V-Twin、KTM 大单缸）以及风冷甲壳虫与重卡柴油直六。

38 款跑车仪表盘：涵盖保时捷（911 GT3 钛灰、911 S/T 经典绿字、GT3 RS 竞速黄、918 Spyder 酸绿、930 Turbo、992.2 全液晶）、法拉利（458/812 经典黄底、488 Pista 赛道红、F40 复古黑橙、Testarossa、SF90）、兰博基尼（Aventador 战斗机、Huracán CORSA、Countach、Miura、Revuelto）、经典跑车（奔驰 300SL 鸥翼、捷豹 E-Type、阿斯顿·马丁 DB5、谢尔比 Cobra 427、福特 GT40、宝马 E30 M3）与现代超跑/JDM（雷克萨斯 LFA、迈凯伦 P1/720S、帕加尼 Huayra、布加迪 Chiron、奥迪 R8、AMG GT、宝马 M4、科尔维特 C8、福特 GT、柯尼塞格 Jesko、GT-R R34 Nismo、Supra MK4、NSX NA1、RX-7 FD、本田 S2000）。
